# Bus o’Clock UX review implementation

Approved scope: the user accepted the six recommendations from the live-site review and authorized testing, GitHub upload and Pages deployment.

1. Keep language selection on the welcome page and in Settings only. Provide a return action in Settings that preserves the interrupted form/map. Use browser language when no saved preference exists.
2. Extend route search with service groups (route, direction, service type); select a destination before showing boarding stops in sequence. Preserve repeated stops by sequence and exclude terminal-only entries. Keep name and nearby searches.
3. Add a direct boarding action to stop cards while preserving map selection and walking navigation.
4. Collapse optional time plans, retain existing presets, label manual estimates and show an input-driven, explicitly hypothetical ten-minute arrival example.
5. Compact header and spacing. Translate new strings in all nine supported languages.
6. Verify data grouping, terminal exclusion, language persistence, draft preservation, preset switching and browser workflows. Build web assets, commit and push feature branch, publish built assets to existing gh-pages branch; verify live app.
